# Quantum Tunnelling (Video 4, 60-second short)

An animated vertical short built in code with Remotion and three.js; last topic of Season 1.

**Render on your PC:** install Node.js, then double-click `render.bat` (uses your computer's graphics card, attaches `voiceover.wav`). `test_render.bat` makes a 30-frame test.

- `quantum_tunnelling_with_voiceover.mp4`: cloud preview with sound (the PC render is sharper)
- `script.md`: lines, timings, fact map, and the decisions I made
- `voiceover_script.pdf`: the text, if you record your own voice
