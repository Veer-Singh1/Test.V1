# The brickworks that woke up a country (Durban, 1973)

A 43-second vertical animated story for EMS Module 14 (Trade Unions). It's built entirely in code with Remotion and three.js.

**Render on your PC:** install Node.js, then double-click `render.bat`. It uses your computer's graphics card. Put `voiceover.wav` in this folder first if you have one, and it gets attached. `test_render.bat` makes a 30-frame test.

- `script.md`: script, fact map and sources
- `voiceover_script.pdf`: the text to read
- `camera_plan.md`: shot-by-shot camera plan
- `PROGRESS.md`: what's done and what's next
- `stills/contact_sheet.png`: one still per shot
- `npm run studio`: open the live preview
