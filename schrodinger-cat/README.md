# Schrödinger's cat (60-second short)

A 64-second vertical animated short built in code with Remotion and three.js. It's the second video in the series after the double-slit short, with the same host, lab and generated voice.

**Render on your PC:** install Node.js, then double-click `render.bat`. It uses your computer's graphics card and attaches `voiceover.wav`. `test_render.bat` makes a 30-frame test.

- `schrodinger_cat_with_voiceover.mp4`: cloud preview with sound (no supersampling; the PC render is sharper)
- `script.md`: script, timings, fact map, and the decisions I made while you were asleep
- `voiceover_script.pdf`: the text to read if you record your own voice
