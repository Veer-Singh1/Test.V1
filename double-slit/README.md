# The double-slit experiment (60-second short)

A 64-second vertical animated short built in code with Remotion and three.js. The voiceover is generated (Kokoro TTS).

**Render on your PC:** install Node.js, then double-click `render.bat`. It uses your computer's graphics card and attaches `voiceover.wav`. `test_render.bat` makes a 30-frame test.

- `double_slit_with_voiceover.mp4`: cloud preview with sound (no supersampling; the PC render is sharper)
- `script.md`: script, timings, fact map, what changed from your draft
- `voiceover_script.pdf`: the text to read if you record your own voice
- `scripts/synth_voiceover.py`: how the voiceover was made
- `npm run studio`: live preview
