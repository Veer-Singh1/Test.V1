# The Heisenberg Cop

An animated vertical short built in code with Remotion and three.js; part of the quantum series.

**Render on your PC:** install Node.js, then double-click `render.bat` (uses your computer's graphics card, attaches `voiceover.wav`). `test_render.bat` makes a 30-frame test.

- `heisenberg_cop_with_voiceover.mp4`: cloud preview with sound (no supersampling; the PC render is sharper)
- `script.md`: lines, timings, and the decisions I made
- `voiceover_script.pdf`: the text, if you record your own voice
